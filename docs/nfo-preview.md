# NFO 只读预览

安装包将 MediaAtlas 注册为 `.nfo` 的可选查看器（`Viewer` / `Alternate`），不自动抢占系统默认应用。通过系统“打开方式”关联后双击打开独立预览窗口，不带应用顶部工具栏或左侧菜单；侧栏不再提供 NFO 入口。独立窗口使用应用内精简标题栏与拖拽区域：macOS 沿用 Overlay 和原生三色按钮，Windows / Linux 复用共享最小化、最大化/还原与关闭控件；窗口操作失败仍可重试。多文件窗口只操作各自当前窗口，不新增媒体库或文件访问权限。正常 Linux 媒体库窗口仍保留系统窗口框。

关联启动优先判断 NFO 模式，跳过媒体库数据库、任务恢复、监控和扫描初始化；普通启动才执行原媒体库初始化。Windows / Linux 的关联参数与 macOS 的文件打开事件使用同一只读解析入口。macOS 冷启动的首个文件使用尚未选择模式的窗口，后续文件逐个新建窗口；若普通媒体库已经启动，预览始终使用新窗口，不改变原页面。文件路径按窗口保存，关闭后清理；读取命令不接收前端路径，也不能取走其他窗口的文件。若 macOS 文件事件晚于普通启动模式判定，既有服务可能已初始化，但该文件不会执行导入、刮削或旁车写入。

预览读取系统关联给出的单个文件，不提供接受任意路径的读取 IPC、不遍历同目录、不使用媒体库权限。NFO 最大 2 MiB，要求 UTF-8；XML 复用本地解析器，拒绝 DTD / 外部实体，纯文本按文本显示。所有字符串以 React 文本输出，不执行 HTML。终端符号链接不跟随，读取和大小检查基于同一个文件句柄。

海报和背景从 NFO 的 `thumb` / `fanart` 引用读取，每类最多尝试三项。离线图片使用读取 NFO 时已打开的目录句柄，只允许其内部相对路径，逐级拒绝符号链接、父目录跳转、绝对路径、盘符和 UNC。远程图片通过现有 NetworkEngine 读取公网 HTTPS，复用 DNS/IP、重定向、凭据及代理边界，不读取用户 Token、不修改来源启用设置；拒绝私网与不受信任的环境代理。单图最大 8 MiB，只解码 PNG/JPEG/WebP，复用全局双并发解码预算和既有像素/内存上限，缩放到 1280×960 内并重编码为 PNG data URI。每类图片加载最多六秒；图片失败仍展示文字。原文件不被改写，预览不入库、不写缓存，也不持久化文件内容。

XML 预览与影视库共用 `MediaDetailView`、`MediaDetailSections`、`MediaCast` 和 `MediaMetadataFields`，覆盖大背景、海报、标题、年份、评分、简介、事实网格以及演员、元数据和图片标签页。标签页列表、选择与键盘切换采用同一实现；NFO 不传入本地媒体文件、季集、关联条目、库内状态与操作。只展示实际可用资料，缺图时省略；演员角色、来源评分及票数、电影系列、来源 ID 保留为可读内容，不再 JSON.stringify，图片引用不作为文本清单输出。XML 原文留在元数据内按需展开。独立预览无需 QueryClient 或 Router；普通影视库继续保留真实来源查询、系统应用打开和资料处理入口。

有背景图时，共享详情中的海报与正文在宽屏上移 64px，叠入背景图下半部；Hero 同时预留底部空间，避免长标题及操作与正文相撞。760px 及以下取消叠放，缺图时不留空的 Hero。标题栏固定，详情在窗口内滚动，并为键盘焦点留出顶部空间。此布局为基于用户截图的静态调整，尚未实机验收。

macOS 包声明支持 `zh-Hans` 和 `en`，原生选择器标题使用当前应用语言。[Apple 的 bundle 本地化声明](https://developer.apple.com/documentation/bundleresources/information-property-list/cfbundlelocalizations)允许系统选择中文资源；原生固定按钮和侧栏仍由 macOS 为该应用选择的语言控制。Tauri 当前对话框 API 没有设置文件选择器确认按钮文字或运行时系统语言的接口。若应用内切换与系统面板语言不同，可在 macOS 的“语言与地区 → 应用程序”中选择 MediaAtlas 的语言；这里不修改系统全局语言或用户偏好。[Tauri 对话框源码](https://github.com/tauri-apps/plugins-workspace/blob/v2/plugins/dialog/src/commands.rs)
