# 桌面导航、窗口与通知

## 当前行为

- 媒体库总入口可点击，二级分类使用现有电影、电视剧、动画、音乐及按设置启用的成人资源。搜索、排序、健康筛选不改变所属菜单的选中状态；侧栏固定，右侧内容滚动。
- 共享 Select 重置标准和 WebKit `appearance`，使用主题边框、深色表面、单个下箭头，保留原生选值、键盘和 change 契约；展开菜单仍由操作系统管理。
- macOS 使用 Tauri Overlay、隐藏标题文字并保留原生三色按钮；侧栏品牌为按钮留空。Windows 隐藏系统标题栏，右上角通过 Tauri API 实现最小化、最大化/还原、关闭，并响应焦点与窗口状态。Linux 保留系统窗口框。
- 搜索、语言与窗口按钮明确排除拖拽区域；空白工具栏/品牌区域可拖动，双击遵循 Tauri 平台行为。窗口 API 失败提供可重试反馈。
- 全应用只挂载一个 shadcn Sonner。保存、导入、打开请求、任务提交、合并和输出等即时操作结果通过 toast 反馈；加载、字段校验、任务历史、可恢复错误及带恢复动作的结果保留在对应位置。通知不包含凭据、用户路径或成人标题，迟到的过期操作不产生通知。

## 2026-11-06 切页衔接

- 路由先准备目标模块与必要只读查询，复用页面自身的 query options 和 QueryClient，再提交目标视图；不再用整页 Loading 立即替换当前画面。仅首次没有已展示页面时显示启动加载。
- 对已访问但缓存被清空的页面同样采用 blocking stale reload，避免返回时重新闪出页面内部 Loading；快速连续导航忽略过期目标。固定历史地址在 beforeLoad 中重定向，不先提交空白中间页。
- 图片、来源状态、历史和保存队列等辅助资料后台预取，失败不阻止仍可使用的主内容；已失效的队列条目保留恢复页面。模块或必要资料失败提供安全的错误与显式重试。
- 隐私 Provider 仍负责原有手动设置和后台会话授权，路由准备只读取最新授权快照。关闭成人内容同步取消在途准备并清除私有查询缓存，保留已有页面的即时权限保护，不以平滑切换延迟撤权。
- 音乐页的站内链接改为共享 Button 组合 Router Link，避免重新加载整份桌面前端；外部资料链接仍走原有边界。

新增真实 memory Router 的延迟模块/查询、连续导航、失败重试及清缓存后返回用例，并核对队列恢复、可选资料失败和同步撤权。本会话不在本地运行项目、测试、构建或安装；执行结果以当前提交云端 CI 为准，仍未进行本轮真实窗口验收。下方历史验证记录不替代本次结果。
