# Phase 2 媒体库界面规范

状态：P2 实施范围。界面消费 [版本化 IPC](phase-2-contract.md)，扫描业务见 [library-workflow.md](library-workflow.md)。不接入线上 Provider，不使用假海报或虚构媒体填充页面。

## 布局与导航

桌面采用侧栏导航和主工作区，提供 Dashboard、Media Library、File Scanner、Task Center、Settings。类型入口作为同一媒体库查询的过滤条件；当前没有实现的在线 Scraper/Providers 不展示为可执行功能。Root 管理可在扫描页或设置页完成。

Header 提供语言选择和成人内容显示开关。Root/媒体类型/搜索/健康/排序/视图模式等可恢复的浏览状态写入路由参数；本地个人偏好单独持久化。切换页面不能改变已创建扫描任务的不可变输入。

## Dashboard

显示来自本地数据库的普通媒体总数、Root 数、待确认/失败任务和缺失数据概况，并链接到对应过滤后的媒体库或任务页。成人内容默认不进入统计或最近条目；无数据时引导添加 Root 和扫描，不展示 Demo 统计。

## Root 管理与扫描页

Root 表单包含名称、绝对目录、媒体类型、启停、排除规则；Mixed 必须显式选择。提交验证错误按稳定错误码本地化。移除提示清楚说明只从库中移除、不删除源文件；活动扫描时禁止无声移除。

扫描页选择一个启用 Root，启动后显示持久化任务状态、已访问文件数、候选数、警告及取消按钮。扫描结果采用分页表格或候选列表，显示相对路径、类型、标题、年份/季集/番号线索、文件分段、识别不确定原因及 unchanged 状态。

用户显式勾选候选并确认入库。确认按钮展示当前选中数量、提交中和错误状态；不得默认自动确认全部结果。重复确认返回幂等结果，不把 unchanged 描述为新导入。

## 媒体库与详情

- Poster Wall/List View 切换；共同支持服务端分页、搜索、Root/类型/健康、可用 Facets、排序。
- 海报卡片至少显示本地缩略图或明确占位、标题、年份、类型和健康标记。只请求当前页，图片延迟加载，不读取全部原图。
- 列表显示同一真实媒体集合，批量选择与当前分页相符；P2 不提供尚未实现的在线重新刮削或文件整理按钮。
- 详情显示标题、类型、年份、本地文件列表、外部 ID、字段来源、图片和已入库的季集/分段关联。类型专属信息按可用本地数据展示，不生成假评分、演员或简介。
- 空库、无结果、加载中、请求失败、详情已移除和无可用图片为独立状态，均有可操作的恢复入口。

## 任务中心

任务列表来自持久化记录，显示 Root、时间、状态、访问/候选/导入计数及稳定错误原因。Queued/Running 可取消，WaitingForUser 可打开预览，Interrupted 提示重新启动扫描；终态任务不能显示仍可操作的运行按钮。

进度事件只触发当前相关 Query 刷新。事件丢失或用户切换页面后仍可重新查询真实任务状态。任务日志和错误不展示原始内部堆栈、凭据或无关用户路径。

## 成人内容隔离

入口和开关默认关闭。关闭时不请求成人 Root/条目/任务/Facet/统计或海报，也不从缓存显示上次选中的成人详情。用户明确开启后才以独立 Root/类型查询显示；关闭时清理对应查询缓存与选择，普通媒体墙和 Dashboard 不自动混入成人封面。

P2 的显示开关不是 PIN/系统认证，不宣称提供身份验证；如后续增加锁定能力需独立实现和验收。

## zh-CN / en-US

UI 暂时只支持简体中文 `zh-CN` 和美式英语 `en-US`。默认 zh-CN，缺失翻译回退到 en-US；现有 `en` 资源、选项、调用和测试在 P2 统一迁移。用户手动选择写入本地偏好，启动时恢复；非法或已不支持的保存值回退到默认，不把它当成第三种语言。

导航、按钮、表单、弹窗、分页、加载/空/错误/取消/确认状态和健康文案全部走翻译键。日期、时间及数字按当前 UI locale 格式化；稳定枚举、错误码、字段 ID 和数据库元数据 locale 不随界面语言变化。切换 UI 语言不覆盖媒体原始标题或已入库来源值。

验收检查两种语言下的操作路径、切换后重启恢复、缺失翻译回退、无裸翻译键、旧 en 选项消除和英文长文本布局。

## 可访问性与性能

表单和图标按钮有可识别标签；加载/完成状态可由辅助技术读取；键盘可操作选择、取消、分页与对话框。内容不依赖仅颜色区分异常。界面响应不等待目录扫描结束；1000 条记录仅请求当前页，10,000 文件候选通过分页访问，取消有明确反馈。

浏览器预览保留“需要桌面应用”的真实提示；测试通过显式 Mock/Fixture 注入数据，不在产品运行时伪造 IPC 或媒体记录。
