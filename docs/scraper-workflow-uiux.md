# 刮削工作流与桌面交互优化

调研及实施日期：2026-11-06。基线为 beta.13 源提交 `8e0fae9`，本篇记录后续增量；未运行第三方工具，也未进行本机应用或视觉验收。

## 公开依据与取舍

| 来源 | 观察 | MediaAtlas 的处理 |

社区问题仅是定性证据，不据此声称发生频率或工具排名。没有复制这些工具的自动重命名、批量覆盖或播放器能力。本轮不修改 NFO XML 契约。

## 实际改动

1. **检索与核对。** 候选显示去重后的实际来源 ID、原名、类型和年份，不虚构匹配分数或封面。更改标题、年份、外部 ID、来源或语言后，旧结果保留可读但不能继续选择；重新提交使用当时的查询快照。恢复历史时回填真实保存条件，目标实体保持不变。
2. **合并基线。** 确认与输出成功后失效实际消费者，包括工具详情、工具清单、目标选择列表及媒体库筛选。当前本地基线刷新后再完成动作状态；普通更新不触发成人查询。已有锁定、人工字段和后端预览校验继续生效。
3. **独立输出。** 有效目标、类型一致、无字段/图片/身份变更且无校验错误时，可以预览已保存资料输出。文件路径、新建/更新/保留决定及覆盖后果常显，完整 NFO 文本按需展开；图片不以哈希作为内容展示。写入仍要求有效预览与单独点击，关闭完成预览不冒称撤销写入，新预览不复用旧成功状态。
4. **队列恢复。** 选项显示真实条目状态，失败/暂缓条目可辨识。切换不自动重试或确认；没有增加跨权限标题查询或伪造媒体记录。
5. **后端重复请求。** 同一服务内同一次检索的同一候选详情使用候选级锁，获锁后重新核验会话、授权与缓存。普通、成人实例独立；不同候选可并行；取消等待者不影响已有请求；失败不作为成功缓存，后续可重试。锁表只保留活跃请求或等待者的弱引用，不积累历史任务。

## 验证与范围

遵守会话限制，本地只阅读、编辑与静态 diff 检查，不运行项目、测试、构建或安装依赖。新增前端行为测试覆盖旧结果禁选、历史恢复、缓存更新、补空缺、零变更输出、显式文件写入和队列状态；后端模拟上游测试覆盖并发合并、取消、失败重试及授权撤销。实际结果以本轮云端检查和发布流水线为准。

未更改媒体源文件只读、既有 NFO 默认保留、目录离线图片授权、Token 手动配置、成人缓存隔离或安装包许可材料分离策略。未新增依赖；未实现新的批量自动覆盖、任务调度器、目录 DTO 或播放器。

已确认但不在本轮扩大修改的后端范围：合并事务提交后的自动 NFO 输出仍受已有合并锁保护，离线图片较慢时可能拉长后续合并等待。缩短该临界区需要单独证明同一媒体并发输出与预览版本安全，不以简单解锁替代。
