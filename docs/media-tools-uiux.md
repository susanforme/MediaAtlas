# 媒体工具 UI/UX 调整

2026-11-06，目标为 MediaAtlas 桌面端的本地媒体管理用户。本轮覆盖媒体工具入口、二级导航、资源列表、逐项核对入口、文件整理及检查与监控，不增加后台能力或改变媒体写入授权。

## 公开实践与判断

| 来源 | 公开指南中的实践 | 本次应用 |
| --- | --- | --- |

| [tinyMediaManager：Movie Panel](https://www.tinymediamanager.org/docs/movies/moviepanel) | 媒体列表提供基础资料、搜索筛选，并能进入媒体资料与图片详情 | 合并海报、标题、年份和类型；保留已有服务器筛选，选中资源的本地工具位于列表上方 |

以上是设计系统和同类开源产品的公开实践，不是 MediaAtlas 用户投诉频率或实际可用性测试的结论。

## 源码发现与实现

- 原二级切换仅用 useState 保存，刷新会回到本地资源；健康视图现进入受校验的 URL 状态。导航字段不进入普通媒体查询或持久核对队列的后端筛选契约。
- 原 `/scraper` 不属于侧栏工具的选中范围；现保留工具组及刮削子项选中态，点击当前刮削入口保留 session/queue/media，不重建核对队列。
- 原未选资源也显示禁用批量入口；现按选择显示批量工具条，批选期间禁用行级跳转，避免误离开所选批次。清空或改变筛选仍清除失效选择，最多 32 项、去重保序和成人隔离保持。
- 原详情在分页下方，用户打开后不易发现；现置于列表前，打开后聚焦内容，关闭返回对应行的触发器。文件整理按需展开，预览、确认、回滚和取消继续由原 hook 管理。
- 目录监控用独立状态 Badge 显示运行、待补查与异常，加载和目录缺失有反馈。健康检查仍由用户显式触发，空结果有明确状态，修复入口使用站内导航返回选定资源。

所有样式使用已有 Tailwind utility 和共享 shadcn 控件。没有新增依赖、虚构计数或预览后自动执行。
