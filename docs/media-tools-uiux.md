# 媒体工具 UI/UX 调整

2026-11-06，目标为 MediaAtlas 桌面端的本地媒体管理用户。本轮覆盖媒体工具入口、二级导航、资源列表、逐项核对入口、文件整理及检查与监控，不增加后台能力或改变媒体写入授权。

## 公开实践与判断

| 来源 | 公开指南中的实践 | 本次应用 |
| --- | --- | --- |
| [GitHub Primer：UnderlineNav](https://primer.style/product/components/underline-nav/guidelines/) | 视图有独立 URL、明确默认项；导航保持精简，单个视图支持完成任务 | 本地资源 `/tools`、资料刮削 `/scraper`、检查与监控 `/tools?view=health`；桌面子菜单与窄屏横向导航复用同一组件 |

| [tinyMediaManager：Movie Panel](https://www.tinymediamanager.org/docs/movies/moviepanel) | 媒体列表提供基础资料、搜索筛选，并能进入媒体资料与图片详情 | 合并海报、标题、年份和类型；保留已有服务器筛选，选中资源的本地工具位于列表上方 |

## 源码发现与实现

- 原二级切换仅用 useState 保存，刷新会回到本地资源；健康视图现进入受校验的 URL 状态。导航字段不进入普通媒体查询或持久核对队列的后端筛选契约。
- 原 `/scraper` 不属于侧栏工具的选中范围；现保留工具组及刮削子项选中态，点击当前刮削入口保留 session/queue/media，不重建核对队列。
- 原未选资源也显示禁用批量入口；现按选择显示批量工具条，批选期间禁用行级跳转，避免误离开所选批次。清空或改变筛选仍清除失效选择，最多 32 项、去重保序和成人隔离保持。
- 原详情在分页下方，用户打开后不易发现；现置于列表前，打开后聚焦内容，关闭返回对应行的触发器。文件整理按需展开，预览、确认、回滚和取消继续由原 hook 管理。
- 目录监控用独立状态 Badge 显示运行、待补查与异常，加载和目录缺失有反馈。健康检查仍由用户显式触发，空结果有明确状态，修复入口使用站内导航返回选定资源。

所有样式使用已有 Tailwind utility 和共享 shadcn 控件。没有新增依赖、虚构计数或预览后自动执行。

## 验证边界

遵守本会话约束，仅静态读取和修改；未执行本地项目、测试、类型检查、格式化、构建、截图或安装。补充 URL 导航、当前项、会话保留、成人通道、选择清理与焦点回归；执行结果以本提交云端 CI 和 beta.12 发布矩阵为准。1648×928、窄屏、键盘完整路径及真实系统交互尚未实机验收。

## 2026-11-06 截图设计修订

用户补充了本地资源、资料刮削、检查与监控三个当前原生界面截图，并授权结合已有页面截图和源码进行设计。两个 subagent 分别查看主页面和历史合并/窄屏图片，生成三张设计参考后实现一套保持现有主题的紧凑工作台。生成图只作设计参考，不是新版本运行截图，也不作为真实资料、状态或可用性验证。

| 视图 | 截图可见的问题 | 采用的调整 |
| --- | --- | --- |
| 本地资源 | 主次动作分散、保存队列铺屏、单行列表占用整块卡片、分页分居两端 | 子页名称与一组小动作对齐；轻量行表；可折叠队列与非零状态；分页靠近列表右侧 |
| 资料刮削 | 未选本地目标时选择区仍占大段首屏，来源平铺重复不可用原因，主检索动作处于底部 | 目标按需展开；查询字段与检索动作同组；可用来源优先；结果、合并、输出及历史保持独立层次 |
| 检查与监控 | 两个大卡片粘连，少量状态占用大块容器，运行前状态不明确 | 用间距与细分隔线分组；目录名、监控选择和状态同行；保留实际写入后果提示；区别尚未检查、进行中、失败与本批无问题 |
| 二级菜单 | 工具组缺少媒体库已有的展开箭头，紧凑侧栏子项不可见 | 沿用媒体库的父项链接、独立箭头、默认展开和有名称的图标；收合不导航，不丢失会话及筛选 |

覆盖三个主路由及本地详情/文件整理、批选、检索结果、实时合并/对比、输出预览、持久队列与失败恢复。仅有历史图片的子状态按当前源码核对；没有重新截图或运行，不能声称本轮视觉、键盘或系统交互已验收。Computer Use 因未获应用访问而未能采集，用户随后选择已有截图与源码流程。保持只读媒体、独立确认输出、锁定/手改字段、预览取消与过期响应保护以及普通/成人隔离，不新增依赖。
