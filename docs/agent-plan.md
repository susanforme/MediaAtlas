## 媒体库使用边界（用户补充）

- 媒体库是已刮削资源的只读消费入口，提供浏览、搜索、筛选、海报、详情及打开/观看/收听。扫描候选、未完成刮削和待确认变更放在对应工作区，不作为已完成资源展示。
- 资源的打开/观看/收听动作调用当前操作系统为该本地文件关联的默认应用；不内置播放器、解码播放、转码或流媒体服务。优先采用成熟的 Rust 库或 Tauri 官方插件（例如 `open` / `tauri-plugin-opener`），实施时核对平台支持与安全接口。
- 扫描、刮削、候选选择、元数据合并、标签写入及文件整理在独立工作区执行，继续遵循 Preview → 显式确认 → 执行 → 记录；媒体库页面不承担这些写入操作。视频、独立成人库和音乐库均遵守此边界。
- 打开操作仅由用户明确点击触发。前端传文件 ID，后端重新核对 Root、文件关联、当前文件状态及成人访问权限，再将有效本地媒体文件交给系统关联应用；不接收任意 shell 命令、可执行程序或外部 URL。多个媒体文件须明确选择，不猜测要打开的版本或 Part。
- 原生打开接口报告“已提交系统打开请求”或明确错误，不把进程启动等同于播放成功。网页模式提示桌面运行要求；Windows/macOS/Linux 系统关联需要分别验收。
- 此处为最新产品约束，覆盖早期阶段将编辑动作混入媒体库详情的描述。历史实现的调整须在后续阶段记录：P6 组织独立音乐工具区；P7 复核媒体库只读边界与原生打开；P8 完成平台验收记录。补充计划不代表这些迁移或平台验证已经完成。

Phase 2 国际化补充（用户指定）：

- UI 支持语言限定为 `zh-CN`、`en-US`，默认 `zh-CN`，缺失翻译回退到 `en-US`。P2 已将旧 `en` 资源与语言选项迁移为 `en-US`，并兼容已保存的旧 `en` 偏好。
- 导航、按钮、表单校验、弹窗、空/加载/错误状态统一走 i18n；后端稳定错误码由 UI 本地化，内部枚举和字段 ID 不随语言变化。日期及数字按当前 UI locale 格式化。
- 用户手动切换后保存选择，重启可恢复；不增加其他 UI 语言。此限制不约束媒体原始标题、Provider 原文或已有元数据 locale，不因切换 UI 语言覆盖媒体数据。
- 验收覆盖两种语言切换、重启恢复、缺失翻译回退，以及主要页面/状态文案；不出现裸翻译键、混用旧 `en` 选项或因英文文本长度造成的关键操作遮挡。

测试与门槛：扫描 Fixture 目录→预览→确认入库→查询/UI 浏览集成测试；重复及增量扫描无重复条目；1000 条记录分页浏览；10,000 文件扫描可取消且 UI 不冻结。海报缺失显示占位，不加载所有原图。

## 阶段验收记录模板

每阶段将以下内容保存至 `docs/acceptance/phase-N.md`，本次不提前生成成功记录：

```markdown
# Phase N 验收记录
- 状态：待验收 / 未通过 / 已通过

- 已完成任务 ID 与文件路径：
```

本轮按最新授权由 subagent 连续执行后续阶段。P3验收后提交并推送，随后进入P4真实Provider、匹配/合并、NFO/图片输出。历史平台验收待办继续保留，不因自动继续而回填未验证结果。
