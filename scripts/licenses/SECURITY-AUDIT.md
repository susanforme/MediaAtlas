# Dependency audit — 2026-11-03

The audit is recorded with advisory IDs, affected ranges, database revision and command evidence in `security-audit.json`. It is not a claim that third-party software is free from defects.

`pnpm audit --json` initially reported five development-tool findings: three moderate findings in Vitest/mocker and two critical findings in tinypool. The test runner was upgraded from Vitest 3.2.7 to 4.1.12 (`^4.1.11`), which removes the affected old dependency graph. The actual post-install audit reports zero findings at every severity. Tests still need to pass through the phase's complete frontend check; the security audit does not substitute for those tests.

`cargo-audit 0.22.0` used RustSec database commit `263a4d951a0867d4bddc29dddd6d59427c78f9a7` (last updated 2026-11-02). The complete lockfile contains `rsa 0.9.10`, affected by unpatched **RUSTSEC-2023-0071** (Marvin timing side channel). `cargo tree --workspace --locked --target all -i rsa` reports no selected dependency: this is a retained optional SQLx adapter dependency, while the application enables SQLite only. The application does not perform RSA operations or store RSA private keys. The finding remains in the audit record; it has not been silently suppressed. Reassess if SQLx adapter/features change.

**Residual Linux framework warning: `glib 0.18.5`, RUSTSEC-2024-0429.** Its `VariantStrIter` iterator implementations are unsound. RustSec identifies versions `>=0.20.0` as fixed, which are incompatible with the current GTK3/WebKitGTK/Tauri dependency types. The whole resolved registry/workspace source graph was searched for both `VariantStrIter` and its `Variant::array_iter_str` constructor. All 17 matches occur inside glib's own definitions or its tests; the application, GIO/GTK/WebKit, and Tauri/Wry/Tao sources do not call or construct this affected iterator. This static assessment reduces the observed exposure; it does not prove the whole framework or native stack safe. The warning remains open. A compatible upstream framework migration and any new variant string-array use must be reviewed before declaring it resolved.

RustSec also reports upstream maintenance notices for `fxhash`, `paste`, `proc-macro-error`, `zbus_names`, `zvariant`, and `zvariant_derive`. These arrive through the scraper/tag and desktop credential/framework dependencies. No incompatible replacement or unsafe blanket version override was applied merely to remove warnings. Track maintained upstream replacements; rerun both audits after dependency updates. No RustSec finding is ignored by configuration.

This beta distributes Linux deb and excludes AppImage because actual bundled native licensing/source materials have not been completed. A future AppImage requires its distribution's native security updates and a separately checked actual-file inventory. RustSec and npm audits do not audit the operating system's GTK/WebKit libraries. Unsigned beta packaging and lack of platform installation/playback testing remain separate release limitations.
